## Key figures (dashboard, data to July 2026)

- Total sales: ₹1.5M (INR) and $18.2K (USD)
- Orders: 690 (405 completed, 285 processing)
- Average order value: about ₹2,145
- Top product: Agnijith 90 g, about 62% of sales
- Repeat rate: 6.8% (93.2% of customers bought once)
- Payments: 99.1% prepaid
- Markets: India 88.3%, international 11.7%
